# QuizGame
An interactive Android Quiz Game built with **Kotlin** and **Firebase Authentication**.  
Includes Google Sign-In, email/password authentication, and session management for smooth user experience.

---

## 🚀 Features

- Firebase Authentication (Email & Google Sign-In)
- Multiple-choice quizzes with scoring
- Real-time progress and feedback
- Clean and responsive UI
- Developed with Kotlin + Jetpack + ViewBinding

---

## 🛠️ Tech Stack

| Category | Technology |
|-----------|-------------|
| Language | Kotlin |
| UI | Android XML + ViewBinding |
| Backend | Firebase Authentication |
| IDE | Android Studio |
| Build | Gradle (KTS) |

---

## 📁 Main Files
- `MainActivity.kt` – Main menu (Start Quiz, Sign Out)
- `LoginActivity.kt` – Handles user authentication
- `QuizActivity.kt` – Displays quiz questions and handles scoring
- `google-services.json` – Firebase configuration file
